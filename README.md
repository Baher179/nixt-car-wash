# NIXT — منصة خدمات النظافة المتنقلة

<div align="center">

</div>

---

## نظرة عامة

NIXT هو تطبيق ويب من صفحة واحدة (SPA) مبني بـ React 19 و Vite و Tailwind CSS v4،
بواجهة عربية كاملة من اليمين إلى اليسار (RTL). يغطي التطبيق رحلة العميل كاملة
من تصفح الخدمات وحتى إتمام الحجز، إضافةً إلى لوحة تحكم للإدارة.

## المزايا الأساسية

| المجال | التفاصيل |
|---|---|
| **الخدمات** | غسيل السيارات، السجاد، الكنب، الخزانات، ومكافحة الحشرات |
| **المتجر** | كتالوج منتجات، صفحات تفاصيل، سلة شراء، وإتمام الطلب |
| **الحجوزات** | تدفّق حجز متعدد الخطوات مع اختيار الموقع والسيارة والموعد |
| **الحساب** | الملف الشخصي، العناوين، السيارات، الطلبات، والإعدادات |
| **الولاء** | محفظة، نقاط مكافآت، إحالات، هدايا، وكوبونات خصم |
| **الاشتراكات** | باقات وخطط اشتراك دورية |
| **لوحة التحكم** | إدارة الطلبات والخدمات والمنتجات والعملاء |

## التقنيات المستخدمة

- **React 19** — واجهة المستخدم
- **Vite 6** — أداة البناء وخادم التطوير
- **TypeScript 5.8** — أمان الأنواع
- **Tailwind CSS v4** — التنسيق
- **Motion** — الحركات والانتقالات
- **Lucide React** — الأيقونات

## التشغيل محلياً

**المتطلبات:** Node.js 18 أو أحدث

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل خادم التطوير
npm run dev
```

ثم افتح <http://localhost:3000>

## الأوامر المتاحة

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | تشغيل خادم التطوير على المنفذ 3000 |
| `npm run build` | بناء نسخة الإنتاج في مجلد `dist/` |
| `npm run preview` | معاينة نسخة الإنتاج محلياً |
| `npm run lint` | فحص الأنواع عبر TypeScript |

## بنية المشروع

```
src/
├── App.tsx                  # جذر التطبيق والتوجيه بين الشاشات
├── context/AppContext.tsx   # الحالة العامة للتطبيق
├── data/                    # البيانات الأولية وبيانات السيارات
├── types.ts                 # تعريفات الأنواع
└── components/
    ├── common/              # الهيدر، الفوتر، البحث
    ├── client/              # شاشات العميل
    └── admin/               # لوحة التحكم الإدارية
```

## ملاحظات

- التوجيه قائم على الحالة (state-based) وليس على مسارات URL، لذا يعمل النشر الثابت دون إعدادات إضافية.
- البيانات حالياً تجريبية ومخزّنة محلياً — لا يوجد ربط بخادم خلفي.
